# Random Quote Generator

A simple web application that displays random quotes from developers, scientists and thinkers.

I built this project to practice JavaScript and learn how to work with browser APIs.

## Features
- Display random quotes
- Show the author's name
- Copy quotes to the clipboard
- Avoid repeating the same quote twice in a row
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Clipboard API

## Project Structure
- `index.html` – Page structure
- `style.css` – Page design
- `quotes.js` – Collection of quotes
- `script.js` – Application logic
